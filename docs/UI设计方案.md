### 2.3 头像（12 格，卦爻×五行色）
- 概念：圆形头像 + 五行底色 + 三线爻纹（乾/兑/离/震/巽/坎/艮/坤 八象 + 4 延伸色），**每个唯一可辨**；
- 与「爻」主题强绑定，替换现通用 emoji；
- 实现：12 个 128px SVG/PNG，或先用 emoji 过渡（见 §四 落地建议）。

### 2.4 提示框与组件（token 化）
```
--brand: #A32D2D;  --brand-soft: #FCEBEB;  --ink: #2C2C2A;  --paper: #F7F3EC;

空态: 卦爻三线纹灰化 + 一句引导文案（如「暂无数据，去首页发起第一个表态」）
```

## 三、文案审查与修正（三套方案通用）

### 3.1 语气规范
- 统一为**「专业但不冷」**：陈述句为主、避免过度口语与卖萌；
- 所有「你」统一「您」；动词统一（表态/参与/结算/判定）。

### 3.2 需修正文案对照

| 位置 | 原文 | 修正 | 原因 |
|---|---|---|---|
| 详情-重复表态 | 您已表态过啦 | **您已参与过该话题** | 语气统一 |
| 详情-截止 | 该预言已截止 | 该话题已截止参与 | 与「表态」口径一致 |
| 任务-签到 | 连续签到加成 | 连续签到额外奖励 | 表意更准确 |
| 仲裁-理由校验 | 理由过短应拒绝 | 请补充仲裁理由（10-200 字） | 提示即引导 |
| 邀请-标题 | 邀请好友 | 邀友同行 | 与「爻」主题呼应（可选） |
| 荣誉-未解锁 | — | 达成条件后自动点亮 | 补空态文案 |
| 榜单-空态 | — | 暂无上榜用户，快去参与表态 | 补空态文案 |

### 3.3 敏感词防护（WORD_MAP 扩充建议）
现有 `WORD_MAP` 保留并扩充：

```js
WORD_MAP: {
  '下注/投注/竞猜': '支持/表态/投票',
  '赔率/胜率': '支持率/共识指数/预言度',
  '筹码/积分余额': '爻/智慧积分/预言豆',
  '输/赢/庄家': '预言成功/预言未成功/官方判定',
  '奖金/彩金/返水': '奖励/结算返还/荣誉',
  '中奖/中彩': '预言成功/达成目标',
  '博彩/赌博/对赌': '互动/预测交流/观点交锋'   // 提示语与规则页用词兜底
}
```
- 规则页（我的 → 规则说明）需人工过一遍：不得出现「博彩/对赌/赔率」字样，用「预测互动/观点交锋」表述；
- 审核模式 compliance 下按钮文案统一「投票/参与」；full 模式保持「表态/投入」。

### 3.4 提示框（toast/弹窗）文案规范
| 类型 | 规范示例 |
|---|---|
| 成功 | 爻已到账 · 共 +10 爻 |
| 失败 | 操作未完成，请稍后重试 |
| 校验 | 每次表态至少投入 10 爻 |
| 确认 | 投入 20 爻参与「××」，确认？ |
| 空态 | 暂无数据 + 一句行动引导 |
