# 广告与变现说明（合规）

## 1. 结论

本产品**不卖爻、不做任何充值/提现/兑回**（合规红线）。变现主路径是**微信官方广告（流量主）**：用户看广告获得爻，平台获得广告收入——爻是“看广告的奖励”，不是“花钱买的筹码”。

## 2. 微信广告联盟怎么接入

微信小程序有官方成熟的广告体系（微信广告 / 流量主），支持**激励式视频、插屏、Banner、原生模板**等广告位：

### 2.1 开通流量主（前提）

- 门槛：小程序**累计独立访客（UV）≥ 1000** 且无严重违规记录（近期官方有下调至 500 的调整，以小程序后台显示为准），个人主体也可以开通；
- 申请入口：小程序后台（mp.weixin.qq.com）→ 左侧「流量主」→ 开通 → 补充财务资料（后续结算需要）。

> ⚠️ 现实提示：**上线初期（UV 未到门槛前）没有广告收入**。这段时间靠“签到 + 任务 + 荣誉商城”维持爻经济，等用户量上来再开通流量主。

### 2.2 创建广告位并接入

1. 开通后进入「流量主」→「广告位管理」→ 新建「**激励式视频广告**」，复制 `adUnitId`；
2. 填入 `miniprogram/utils/config.js` 的 `REWARDED_VIDEO_AD_UNIT_ID`；
3. 重新编译并部署；
4. 真机验证：任务中心显示“广告位已配置”，点击“看视频领爻”会弹出真实广告，完整观看（`isEnded`）后发放爻。

> 安全加固（推荐）：代码已实现微信广告「服务端奖励回调」`adRewardCallback`（验签 + AES 解密 + 按 `transaction_id` 幂等发放），配置步骤见 `docs/部署检查清单.md`：开通云开发 HTTP 访问服务 → 流量主后台激励广告开启「服务端奖励回调入口」→ 配置 `AD_SSV_TOKEN` / `AD_SSV_ENCODING_AES_KEY` → 把 `claimAdTask` 的 `AD_SSV_ENABLED` 置 `true`。开启后爻以服务端回调为准，客户端无法伪造观看记录。

### 2.3 测试说明

- 开发者工具模拟器：广告组件显示为灰色测试样式，不播真广告；
- 真机预览/体验版：需要真实 `adUnitId` 才能看到真广告；
- 未配置 `adUnitId` 时：代码自动跳过广告直接发放（开发/Mock 模式），任务中心会明确显示“开发模式：未配置广告位”。

当前状态：**服务端回调代码已实现**（`adRewardCallback`，含验签、解密、交易去重与原子发放），尚未在控制台启用；启用后 `claimAdTask` 进入「严格模式」，爻由回调发放。

## 4. 合规注意事项

- 禁止诱导点击、虚假激励（用户未完整观看就发奖）；
- 广告奖励的是**虚拟爻**，与人民币、可变现实物无任何兑换关系；
- 遵守微信广告平台政策（单页广告数量、样式规范），提审素材不含广告诱导文案；
- 激励视频需完整观看（`isEnded`）才发奖，本代码已按此实现。
