# 小程序隐私保护指引（提审材料 · 可直接粘贴公众平台）

> 用途：微信公众平台 → 设置 → 服务内容声明 → **用户隐私保护指引**，逐项填写
> 填写人：小程序运营者（个人主体）

---

## 一、开发者信息

- 开发者主体：个人开发者
- 小程序名称：预测卦局（以平台最终审核名称为准）
- 小程序类型：工具 / 娱乐互动

## 二、我们收集的信息及用途

### 1. 微信登录（OpenID）
- **类型**：账号信息（微信授予的唯一标识，不含手机号、通讯录等）
- **用途**：识别用户身份、同步与保存用户的游戏进度与成绩
- **触发方式**：用户进入小程序时自动登录

### 2. 用户主动填写的信息（雅号 / 昵称）
- **类型**：用户自行输入的文字
- **用途**：在小程序内展示用户身份
- **说明**：用户可随时修改；系统对内容做长度、注入与敏感词校验

### 3. 系统预设头像选择
- **类型**：用户从系统提供的预设头像列表中选择一项（无用户上传图片）
- **用途**：在小程序内展示用户身份
- **说明**：小程序不收集、不上传任何用户图片

### 4. 订阅消息（结果通知）
- **类型**：订阅授权状态
- **用途**：在用户参与的互动结果判定后，向用户推送结果通知（需用户主动订阅）
- **说明**：用户可随时在微信设置中关闭

### 5. 广告（激励视频广告，如开通）
- **类型**：广告标识符（微信广告组件自动处理，开发者不读取）
- **用途**：用户自愿观看激励视频获取虚拟积分，支持小程序运营
- **说明**：广告由微信官方组件提供，不向第三方传输用户个人信息

### 6. 本地存储
- **类型**：本地缓存（如用户浏览记录、表态草稿）
- **用途**：提升加载速度与使用体验
- **说明**：仅存于用户设备，可随时清除

## 三、我们**不**收集的信息

- 手机号、身份证号、通讯录、位置、相册、麦克风、摄像头等敏感信息（本小程序未申请任何此类权限）

## 四、信息共享

- 本小程序**不向任何第三方出售、出租或共享用户个人信息**
- 除微信官方基础设施（云开发存储、广告组件）外，无第三方 SDK 收集个人信息

## 五、信息存储

- 存储位置：微信云开发服务器（境内）
- 存储期限：用户注销后删除；或依用户要求通过客服删除

## 六、未成年人保护

- 本小程序为娱乐互动内容，不要求填写真实身份信息；若为未成年人，请在监护人指导下使用

## 七、用户权利

- 用户可随时修改雅号、更换头像、关闭订阅消息、清除本地缓存
- 用户可通过「我的 → 联系客服」要求删除账号及数据

## 八、更新与生效

- 本指引随功能调整不定期更新，更新后在小程序内公示
