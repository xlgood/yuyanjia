# 云函数/数据库索引一键验收脚本

> 用途：部署后验证关键查询链路与数据库索引是否就绪。
> 用法：微信开发者工具 → Console（调试器控制台）→ 粘贴运行。
> 身份：由小程序自身发起，自动携带当前登录 openid（管理员函数 `getPendingReviews` 需管理员身份）。
> 判定：全部显示 ✅ 即正常；出现 `❌` 且错误含 `index` / 索引 字样 = 缺索引，按 `database/indexes.md` 补建。

```js
// ===== 云函数/索引一键验收（IIFE 包裹，避免 Console 全局变量冲突，可重复运行）=====
(() => {
  const call = (name, data) => wx.cloud.callFunction({ name, data: data || {} })
    .then(r => {
      const ok = !!(r.result && r.result.ok);
      const err = r.result && (r.result.err || r.result.msg);
      console.log('【' + name + '】', ok ? '✅ ok' : '❌ ' + err, JSON.stringify(r.result).slice(0, 200));
      return { ok, err };
    })
    .catch(e => {
      console.log('【' + name + '】❌ 调用失败', e.errMsg || e);
      return { ok: false, err: e.errMsg || String(e) };
    });

  (async () => {
    console.log('===== 开始验证（索引缺失时云数据库会报索引错误）=====');
    // 1) 首页列表：依赖 markets(status+deadline)
    await call('getMarkets', { page: 1, pageSize: 5 });
    // 2) 热门榜：依赖 markets(status+totalPool desc)
    await call('getMarkets', { hot: true, minTotal: 0, page: 1, pageSize: 5 });
    // 3) 天榜四榜：依赖 users(streak/weekPoints/monthPoints/points 单字段索引)
    await call('getLeaderboard', { type: 'streak', limit: 10 });
    await call('getLeaderboard', { type: 'week', limit: 10 });
    await call('getLeaderboard', { type: 'month', limit: 10 });
    await call('getLeaderboard', { type: 'total', limit: 10 });
    // 4) 复核队列（管理员）：依赖 markets(needsManualReview)
    await call('getPendingReviews');
    // 5) 我的记录：依赖 bets(openid+createdAt desc)
    await call('getMyRecords', { page: 1, pageSize: 5 });
    // 6) 公断阁/资格统计：依赖 arbitration_votes(arbitrationId+openid)、bets(openid+status)、pks(status+participantIds)
    await call('getArbitration');
    // 7) PK 中心：依赖 pks 多组复合索引
    await call('myPks', { page: 1, pageSize: 5 });
    // 8) 邀友统计：依赖 invites(inviterId+createdAt desc)
    await call('inviteStats');
    console.log('===== 验证结束：全绿 = 查询/索引正常；含 index 报错 = 缺索引，见 database/indexes.md =====');
  })();
})();
``````

## 覆盖矩阵

| 调用 | 验证的索引 | 缺索引时的报错形态 |
|------|-----------|-------------------|
| `getMarkets`（普通） | markets `status+deadline` | 索引错误 |
| `getMarkets`（hot） | markets `status+totalPool↓` | 索引错误 |
| `getLeaderboard` ×4 | users `streak` / `weekPoints` / `monthPoints` / `points` | 索引错误 |
| `getPendingReviews` | markets `needsManualReview` | 索引错误 |
| `getMyRecords` | bets `openid+createdAt↓` | 索引错误 |
| `getArbitration` | bets `openid+status`、pks `status+participantIds`、arbitration_votes `arbitrationId+openid`、arbitrations `challenger.openid` | 索引错误 |
| `myPks` | pks `challengerId/opponentId+createdAt`、`status+expiresAt` | 索引错误 |
| `inviteStats` | invites `inviterId+createdAt↓` | 索引错误 |

## 无法脚本验证的 1 组

- `markets(status+disputeEndsAt)`：只被 `settleMarket` **批量结算**使用，触发会真实结算市场（有副作用），不纳入脚本。以控制台「索引管理」里能看到该索引为准。

## 补充说明

- 空结果（如 `getPendingReviews` 返回空 list、`getArbitration` 返回 `arbitration:null`）属正常，只要 `ok:true` 即通过
- 腾讯云对**单字段**查询通常自动建索引，对**复合字段**必须手动建（`database/indexes.md` 全清单）
- 控制台核对入口：云开发控制台 → 数据库 → 各集合 → 「索引管理」
